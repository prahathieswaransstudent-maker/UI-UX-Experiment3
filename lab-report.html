1. Aim

Heuristic Evaluation & A/B Testing

To compare the usability of two shopping application interfaces, identify heuristic violations, implement improved designs, and measure whether the redesign changes user behaviour.

2. Objective

  1. Evaluate ShopSphere and MarketCart against Nielsen’s ten usability heuristics.
  2. Rank usability issues by severity and map each to a design change.
  3. Create original and improved variants for both applications.
  4. Test the task “search for wireless headphones and add the best-rated item to the cart.”
  5. Compare completion rate and task time for original and improved variants.

3. Applications Compared

A — ShopSphereLow-density e-commerce interface. Strengths: familiar structure and clear category navigation. Weaknesses: small search affordance and limited status feedback.
B — MarketCartPromotion-heavy marketplace interface. Strengths: visible deals and broad discovery. Weaknesses: denser hierarchy, inconsistent actions, and weaker visual grouping.

4. Heuristic Evaluation Method

Four evaluators would independently complete the search-and-cart task and score the product pages. The assessment uses Nielsen’s 1–5 severity scale: 1 cosmetic, 2 minor, 3 major, 4 usability catastrophe, and 5 unusable. Consensus findings are reported below.

6. Redesign

Implemented Changes

Common improvements for both variants

  • Clear, large search field with task-related placeholder text.
  • Consistent blue primary action for the main task.
  • Persistent cart count and completion confirmation.
  • Visible task progress and product state feedback.
  • Back navigation retained during product detail viewing.

Application A — ShopSphere

Original: simple, familiar layout with light hierarchy and a medium-sized search field.

Improved: stronger search border, taller header, branded primary cart action, and an explicit “Search wireless headphones” affordance.

Application B — MarketCart

Original: warmer promotional treatment, denser card spacing, and a secondary add action placed away from the primary visual flow.

Improved: reduced visual density, standardized card height, consistent action placement, stronger search affordance, and clear cart feedback.

Implementation

The interactive prototype is implemented in HTML, CSS, and JavaScript. It supports competitor and variant switches, timed task completion, progress tracking, a cart count, and persistent local metrics.

7. A/B Experiment

Experimental Design

Hypothesis

H0: The improved variant does not change task completion or time.
H1: The improved variant increases task completion and reduces time.

Independent variable

Interface variant: Original or Improved.

Dependent variables

  • Task completion (yes/no)
  • Task completion time (seconds)
  • Number of attempts

Procedure

  1. Recruit at least 20 participants: 10 per application, with 5 assigned to Original and 5 to Improved.
  2. Randomize the competitor and variant conditions. Use balanced participant IDs.
  3. Provide only the task statement; do not explain interface controls.
  4. Click “Start timed task,” then search, open, and add the highest-rated item.
  5. Record automatic metrics and repeat once after a short break if a learning effect is being tested.

Analysis

Compare completion rates using a chi-square test or Fisher’s exact test for small samples. Compare task time using a t-test if approximately normal, or Mann–Whitney U if not. Report effect size and a 95% confidence interval.

Relative improvement = ((Improved rate - Original rate) / Original rate) × 100

Expected Behaviour Impact

The improved variants are expected to reduce uncertainty at search and cart stages, because the search affordance is more visible and the final action is consistently prioritized. This should increase completion and reduce average task time.

Recommended Statistical Conclusion

Conclude a significant positive effect only when p < .05 and the confidence interval does not cross zero. If the result is not significant, describe it as inconclusive and retain the improved design only as a user-tested candidate.

9. Conclusion

Result

The study identified search discoverability, inconsistent cart feedback, dense visual hierarchy, and weak action consistency as priority usability issues for the compared shopping interfaces.

Both prototypes now include prominent search, clear progress, persistent cart status, consistent actions, and explicit product-state navigation. The A/B runner measures completion and task time so both ShopSphere and MarketCart can be compared across original and improved variants.
